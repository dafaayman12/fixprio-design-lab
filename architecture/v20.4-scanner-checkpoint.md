# V20.4 — Scanner experience checkpoint

Builds on V20.3; follows owner-approved Take App parity and simplicity requirements. No new page.

- POS Scan action and global quick scan from POS open sale mode. Generic and repair entry default to lookup when no draft exists. An unfinished batch in another mode is retained; new scans are blocked until the user explicitly resumes the mode or clears the batch and chooses a mode. Never silently discard a draft.
- Existing POS search supports exact registered QR, barcode and SKU lookup through the shared resolver; only eligible ordinary products can be added.
- Single-step Undo scan restores the quantity before the most recent successful batch scan. Manual edits, removal, commit and clearing invalidate undo. Repeated ordinary product scans still count as distinct units. Review/confirmation remains required; no automatic stock mutation.
- Visual success/error feedback and optional vibration through browser support; no sound or new settings. Mobile idle batch camera preview is compact; live camera retains normal size. Non-purchase adjustment description is explicit, to distinguish it from PO receiving.
