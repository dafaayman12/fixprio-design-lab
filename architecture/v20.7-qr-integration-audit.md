- Strong: deepen identity module (301–312, 1599–1630, 1941–1946). Durable identity authority and domain lifecycle; migrate old labels, prevent collisions and reuse, implement revocation and variant identities. Avoid new microservices.

Deletion test favors retaining these modules and deepening existing interfaces, not adding parallel wrappers. Locality and leverage improve when existing commands own validation and callers need not coordinate state. No new interface/schema approved.
